Welcome to NinoGames
Let's set up your gaming hub just the way you like it
1
Choose Install Location
Select where you'd like to download and install your games.
Make sure you have enough disk space for game downloads
2
Download Options
Configure how NinoGames handles downloads and extraction.
3
Preferred Game Source
Choose your default source for browsing and downloading games.
4
Install Redistributables (Optional)
Install common game dependencies like DirectX, Visual C++, and .NET Framework.
Note: This will use Windows Package Manager (winget) to install .NET Runtime (6 & 8), Visual C++ Redistributables (2005-2022), XNA Framework, and Java Runtime. This may take several minutes and requires administrator privileges. Make sure winget is available on your system (Windows 10 1709+ or Windows 11).
5
Windows Defender Exclusion (Recommended)
Add the NinoGames install folder to Windows Defender exclusions to prevent antivirus from interfering with game files and downloads.
Requires administrator privileges. This helps avoid false positives with game executables.
